# Baucinastatue Mod

Add a static Baucinastatue entity that can transform into a boat to your Minecraft world.

## Features

- Adds a static Baucinastatue entity to your world
- Allows the statue to transform into a boat

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/baucinastatue-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Place the Baucinastatue block in your world.
2. Interact with the block to transform it into a boat.

## Configuration

No additional configuration is required. The mod works out of the box.
